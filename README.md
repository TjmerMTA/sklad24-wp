# Sklad24 — WordPress theme + demo

- `theme/sklad24/` — the WordPress theme (home page of sklad24.com.ua).
- `./build.sh` — packs it into `docs/sklad24.zip`.
- `docs/` — demo page (GitHub Pages): real WordPress in the browser via WordPress Playground,
  installs `sklad24.zip` and opens the home page with the admin bar.

Install on a real site: WordPress → Appearance → Themes → Add → Upload → `sklad24.zip` → Activate.
On first run the theme adds demo content once (new products, reviews, FAQ, menus).
